# Веб-калькулятор стоимости клининга с генерацией заявки в Telegram

Автономный, легковесный и адаптивный одностраничный калькулятор клининговых услуг. Работает без сервера, без базы данных, без внешних библиотек и сборщиков.

## ✨ Особенности

- **Чистый стек**: HTML5, CSS3, Vanilla JavaScript (0 зависимостей).
- **Централизованная конфигурация**: Все тарифы, услуги, контакты и тексты настраиваются в одном файле `config.js`.
- **Локальная работа и хостинг**: Запускается простым двойным кликом по `index.html` (через `file://`), а также публикуется на любом бесплатном статическом хостинге (GitHub Pages, Vercel, Netlify).
- **Интерактивный предпросмотр перед отправкой**: При нажатии «Отправить заявку в Telegram» открывается аккуратное модальное окно на базе нативного HTML5 `<dialog>`. Клиент видит готовый текст заказа, может скопировать его в 1 клик через Clipboard API или перейти напрямую в Telegram.
- **Прямая интеграция с Telegram**: Ссылка формируется в формате `https://t.me/<CONFIG.telegramManager>?text=...` с полным текстом заявки.
- **Поддержка минимального заказа**: Если расчетная сумма меньше `minOrderPrice`, итоговая сумма фиксируется на минимальной отметке и выводится уведомление: *«Минимальная стоимость выезда — ХХХХ ₽»*.
- **Mobile-First UX**: Крупные кнопки переключения, синхронизированный ползунок + цифровой ввод с шагом ±5 м², четкие цифры, контрастная кнопка в фирменном стиле Telegram.
- **Безопасность и приватность**: Без cookies, без LocalStorage, без трекеров.

## 👑 Как открыть скрытую панель владельца

Панель владельца **полностью скрыта от глаз клиентов**. Для входа используйте любой из 4 способов:

1. **По секретной ссылке (самый удобный способ):**
   Просто добавьте `#admin` к адресу вашего сайта: `https://ваш-сайт.ru/#admin` (сохраните в закладки на телефоне или ПК).
2. **Тройной клик по иконке компании:**
   Быстро нажмите 3 раза по значку ✨ в шапке сайта.
3. **Сочетание клавиш на клавиатуре:**
   Нажмите `Ctrl + Shift + A`.
4. **Незаметная точка в футере:**
   Кликните по маленькой точке `·` в конце строки копирайта в самом низу страницы.

### Защита PIN-кодом
При первом открытии панель попросит ввести PIN-код.
- PIN-код по умолчанию: **`1234`**
- Вы можете изменить PIN-код в любой момент в файле `config.js` в параметре `adminPin: "ваш_код"`.

## 🚀 Глобальное сохранение изменений через панель

1. Введите в панели ваш репозиторий (например, `user/cleaning-calculator`) и токен GitHub (создается за 1 клик по ссылке прямо в панели).
2. Отредактируйте любые цены, контакты или минимальный выезд.
3. Нажмите кнопку **«🚀 Сохранить глобально на GitHub Pages»**.
> Изменения отправятся напрямую в репозиторий через GitHub API. Сайт автоматически обновится, и через 30–60 секунд (на Vercel — через 10 секунд!) новые цены станут активны глобально для всех посетителей!

---

### Альтернативные способы изменения цен:
Вам даже не нужен компьютер — можно сделать прямо с телефона через браузер:
1. Зайдите в ваш репозиторий на **github.com**.
2. Нажмите на файл **`config.js`**.
3. Нажмите на значок карандаша ✏️ (**Edit this file**).
4. Измените нужные цифры (цены за метр, доп. услуги, минимум, телефон).
5. Нажмите зеленую кнопку **«Commit changes»** в правом верхнем углу.
> 🚀 **Готово!** Через 30 секунд сайт обновится по всему миру с новыми тарифами.

### Способ 3. Если сайт на обычном хостинге (Beget, Timeweb, Reg.ru)
1. Откройте панель управления хостинга -> «Файловый менеджер».
2. Откройте файл `config.js`.
3. Поменяйте цифры и нажмите «Сохранить».

### Способ 4. Если сайт запущен локально на компьютере
1. Нажмите правой кнопкой на `config.js` -> «Открыть с помощью» -> «Блокнот».
2. Измените нужные цены и нажмите `Ctrl + S`.

  companyName: "Чистый Дом",                // Название компании

  phone: "+7 (999) 456-78-90",              // Телефон

  // 2. МИНИМАЛЬНЫЙ ВЫЕЗД

## 📋 Формат заявки в Telegram

При нажатии на «Отправить заявку в Telegram» формируется сообщение:
```text
Здравствуйте! Хочу заказать уборку в «Чистый Дом»:
- Тип: Поддерживающая
- Площадь: 45 кв.м
- Доп. услуги: Мытье окон (до 3 створок), Мытье холодильника внутри
- Ориентировочная сумма: 4 900 ₽
- Адрес: ул. Тверская, д. 12, кв. 34
- Дата/время: Завтра в 11:00
```
Клиент сначала видит предпросмотр сообщения, может скопировать его в 1 клик или сразу перейти в чат с менеджером.
